# HotDorama Landing Page 🌸

Um projeto de Landing Page moderno e responsivo para uma plataforma fictícia de Doramas (K-dramas). 

## 🛠️ Tecnologias Utilizadas
- HTML5
- Tailwind CSS (via CDN para facilitar a edição rápida)
- FontAwesome (Ícones)
- Google Fonts (Inter)

## 🚀 Como visualizar
Basta abrir o arquivo `index.html` em qualquer navegador web, não é necessário rodar nenhum servidor local!

## ✨ Funcionalidades da LP
- **Design Clean e Romântico**: Paleta de cores focada em tons pastéis de rosa (`brand-500`), combinando com a temática.
- **Responsividade**: Funciona perfeitamente em celulares, tablets e desktops.
- **Seções**: Cabeçalho de navegação, Hero Section com chamadas para ação (CTA), vitrine de "Doramas em Alta" e Rodapé.
